Python code used to generate contours from input images. This is a key step in the pipeline: an input image is processed to extract contours based on shape-dependent characteristics, and the resulting contour data is used as input for a robot motion planning system implemented in MATLAB.

Associated with FANAP. Code: [Photo-Sketch](https://github.com/nematollahsaeidi/Photo-Sketch).
